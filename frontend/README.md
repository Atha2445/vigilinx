# X-CLIP Surveillance Frontend

This is the frontend application for the X-CLIP Surveillance Video Analytics System.

## Features

- Dashboard with statistics overview
- Video analysis with file upload
- Detection logs with filtering
- Prompts management
- Video verdicts history

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Configure Tailwind CSS (if needed):
The project uses Tailwind CSS for styling. The configuration is already included.

3. Start the development server:
```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

### Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Runs the test suite
- `npm eject` - Ejects from Create React App (one-way operation)

## Backend API

Make sure the backend API is running at `http://localhost:8000` before using the frontend.

## Technologies Used

- React 18
- Lucide React (icons)
- Tailwind CSS (styling)
- Fetch API (HTTP requests)
